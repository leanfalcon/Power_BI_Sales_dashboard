# Strategic Sales Analysis — Power BI Dashboard

A sales performance dashboard built in Power BI, developed as part of the Data Analytics Bootcamp at IT Academy (Barcelona Activa).

The project covers end-to-end analysis of sales data: data modelling, KPI design, DAX measures, and interactive visualisations to support commercial decision-making.

---

## What's included

| File | Description |
|------|-------------|
| `sprint_5.pbix` | Initial dashboard — data model, core KPIs and base visuals |
| `sprint_6.pbix` | Final version — refined metrics, drill-through and executive layout |
| `Análisis Estratégico de Ventas.pdf` | Written strategic analysis with findings and recommendations |

---

## Key metrics tracked

- Revenue and sales volume by period, region and product category
- Year-over-year and month-over-month growth
- Margin and profitability by segment
- Top/bottom performers (products and channels)
- Sales trend forecasting

---

## Tech stack

- **Power BI Desktop** — data modelling and report design
- **DAX** — calculated measures and KPIs
- **Power Query** — data transformation and cleaning
- **Excel** — source data

---

## Skills demonstrated

- Dimensional data modelling (star schema)
- DAX: time intelligence, CALCULATE, FILTER, RANKX
- Dashboard design for non-technical stakeholders
- Translating raw sales data into actionable business insight
